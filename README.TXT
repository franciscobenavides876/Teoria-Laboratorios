## 1. Descripción del Repositorio
Este repositorio contiene la implementación, extensiones y simulación de un Autómata Finito Determinista (DFA) en Python, aplicado al modelado del flujo de agendamiento de citas médicas.

El proyecto incluye la resolución de los ejercicios solicitados para el Laboratorio 1:
- Ejercicio 1: Inclusión de selección de médico específico (SeleccionarMedico).
- Ejercicio 2: Flujo de pago en línea antes de la confirmación final (Pago).
- Ejercicio 3: Soporte para múltiples especialidades médicas (broncopulmonar, radiologo).
- Ejercicio 4: Manejo de errores y recuperación al estado inicial (Error).

---

## 2. Estructura de Ramas (Git Workflow)
- main: Rama base y de entrega consolidada.
- Laboratorio-1: Rama de trabajo para el desarrollo, scripts individuales (Lab_01_Ej_*.py) y notebook (.ipynb).

## 3. Requisitos y Dependencias
Para ejecutar los scripts y visualizar los grafos del autómata, se requiere Python 3.8+ y las siguientes librerías:

pip install graphviz ipywidgets

*Nota: Para renderizar los grafos con Graphviz, asegúrate de tener instalado el binario en tu sistema operativo.*
